## 分类规则（重跑时照此判断）

- 活稿 = 主稿 `.tex`/`.pdf` 与 `.bib`；
- 迭代底稿 = `section_1_7_rewrite_draft*`、`section8_rewrite_draft_zh.md`，内容已并入主稿；
- 审查标准 = `*_review_standard_zh.md`，是下次审查的执行依据，不是某次审查的结果；
- 评审 / 审计报告 = 含 `_review_` / `_audit_` / `_reaudit_` / `_closure_`，是某个时点的稿件状态记录；
- prompt 归档 = 文件名含 `prompt`，记录当时下发的工单原文；
- 方案 / 修订说明 = 含 `_plan_` / `_notes_` / `_encoding_`。
