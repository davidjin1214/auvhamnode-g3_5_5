## 1. 复核结论

上一轮审稿分析的主方向成立，但需要以更严格的方式表述：

1. 主稿已经完成从旧方法稿到完整章节初稿的主要转换。旧评审中关于第 6 节命题“应改成引理 + 命题”、第 7 节缺 current evidence 接口、第 8 节为空等问题已经基本解决，不应再作为当前主要问题追踪。
2. 当前最需要处理的不是理论推导错误，而是终稿级的论证强度、证据可复核性、表格组织、机制解释边界和正式中文表达。
3. 上一轮提出的“结论强度需降级”“第 8 节需要集中实验设置与证据来源表”“q-Force 退化机制解释需收紧”“v4_lite 不宜与 eval profiles 混排”“术语与代码/实验管理语言需中文化”等判断，经再次核对后仍然成立。
4. “实验设置表缺失”应精确表述为：相关信息已经散落在第 7--8 节和 README 中，但主稿缺少一张供读者直接复核的集中表格；不是说主稿完全没有说明实验口径。

总体判断：当前主稿可进入终稿级修订。建议先修 P1 项，再做 P2/P3 的文字和版面优化。

## 3. P1：必须优先修改

### P1-1 降低结果结论的因果强度

**位置**

- 摘要：第 44 行。
- 第 1 节贡献段：第 59 行。
- 第 8 节几何结论：第 835 行。
- 第 8 节能量核心结论：第 861--865 行。
- 第 10 节小结：第 949 行。

**问题**

主稿多处使用“必要结构条件”“头号承重先验”等强判断。第 8 节第 835 行已经附带了“本模型族内”“未排除模型容量或正则化等因素”的限制，这说明作者意识到证据边界；但摘要、第 1 节和小结中限制语不够同步，容易让读者把模型族内经验结论误读为普遍理论定理。

**建议**

将强判断统一改为条件化表述：

- “在当前数据协议与模型族下，SE(3) 位姿几何是长期递推稳定性的关键结构因素。”
- “在保持几何与质量结构的前提下，标量势能/机械能量核心是当前模型族中最主要的精度先验。”
- 如必须保留“必要”，应写成“本模型族内的必要结构条件”，且摘要、小结必须同步限定。

**跟踪状态**：`[x] done`

### P1-2 增加集中“实验设置与证据来源表”

**位置**

- 第 7 节长期递推与证据口径：第 773--781 行。
- 第 8 节当前证据口径与数据来源：第 825--829 行。

**问题**

主稿已经说明 current evidence、异常排除和聚合口径，但读者仍需要从多个段落和 README 中拼接实验设置。对于博士论文或投稿稿件，第 8 节应提供一张集中表格，让读者一次性看到：

- 数据来源与数据集标识。
- 训练协议与评估配置。
- 评估模式、预测时域、控制块组织方式。
- 随机种子范围和参与聚合的有效种子数。
- 统计量定义：运行内统计量、种子间聚合方式。
- 异常排除规则：训练异常、递推发散、全 seed 发散时如何报告。
- 结果来源文件：`analysis/section8_current_evidence/per_seed_long.csv` 与 `aggregate.csv`。
- 代码/环境 provenance 是否记录。

**建议**

在第 8.1 小节后增加表格，题名可为“当前证据集的实验设置与聚合口径”。该表不需要引入新结果，只需把现有证据口径集中化。

**跟踪状态**：`[x] done`

### P1-3 收紧 q-Force 退化的机制解释

**位置**

- 第 8.3 小节：第 861--865 行。
- 内部结构诊断：第 904--926 行。

**问题**

当前文本说 q-Force 退化与内部诊断“相互独立地印证”，并进一步说当前 3.76 m 退化“源自能量核心的移除本身”。这个表述过强。energy span 为 NaN 是 q-Force 不定义标量势能后的结构事实，但它不能单独证明位置误差退化的唯一来源。第 861 行已经承认退化可能还包含替换分支可辨识性下降，这与第 865 行的强因果语气存在张力。

**建议**

将表述改为：

- “内部诊断与精度退化在结构解释上相一致。”
- “结果提示标量势能与机械能量核心在当前模型族中承担主要精度作用。”
- “该实验不能把保守势能缺失与替换分支可辨识性下降完全分离。”
