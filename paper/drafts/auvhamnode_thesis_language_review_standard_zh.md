# 本章语言审查标准

## 1. 适用对象与审查边界

本标准适用于 `paper/drafts/auvhamnode_thesis_chapter_zh.tex` 的标题、摘要、十个正式章节、图题、表题及表下注释。审查仅处理中文学术语言和文体，不核查或修正事实、实验数据、公式、推导、参考文献和学术结论。

语言修改不得改变命题方向、因果关系、比较关系、适用条件、证据等级或结论强弱；不得增删研究贡献、技术内容、实验结果或局限性；不得修改数值、模型名称、变量、符号、公式、标签、引用键和交叉引用。若某处只能通过判断内容正确性才能消除疑问，则保持正文不动，并在语言审查记录中列为“超出本轮语言审查范围”。

## 2. 总体原则

1. 准确、严谨、清晰优先于辞藻和句式变化。
2. 修改只服务于语言质量，不改变原文的技术含义和语义强度。
3. 正式而不僵硬，简洁而不损失必要的技术限定。
4. 不以减少字数为唯一目标。定义、条件、边界和例外不得因“精简”而被删除。
5. 不机械追求同义替换或句式多样化。技术术语的一致性高于词汇变化。
6. 长句优先梳理逻辑层级；只有在逻辑关系保持不变时才拆句。
7. 连接词只标示原文已有的逻辑关系，不新增因果、递进、转折或推断。
8. 修改前后的情态词、限定范围、比较对象和否定范围必须保持一致。

## 3. 问题严重度

### A：影响理解或可能产生歧义

包括主谓关系不明、修饰对象不唯一、指代无唯一先行词、否定或条件范围不清、并列层级混乱等。A 类问题原则上必须修改；若无法在不判断内容的情况下消除，则保持原文并记录为超出范围。

### B：明显不符合高水平博士论文文体

包括口语或备忘录语气、超长信息堆叠、明显翻译腔、名词链、图题过载、叙述层级混乱和低信息密度元话语等。B 类问题原则上修改。

### C：可进一步凝练、统一或改善节奏

包括轻度重复、局部节奏失衡、非必要的章节提示、标点和中英文混排不统一等。C 类问题仅在确实提高准确性、连贯性或一致性时修改，不作纯审美改写。

## 4. 十项审查标准

### 4.1 准确与无歧义

- **合格特征：** 每句能够明确还原为“主体—动作或判断—对象—条件”；限定语、否定词和比较对象位置清楚。
- **需要修改：** 主语中途转换、定语悬置、并列对象不属于同一层级，以及“其”“该”“这”“上述”等无唯一指向。
- **越界风险：** 为消除歧义而擅自补充机制、原因、证据、条件或技术对象。
- **判定方法：** 遮蔽公式和引用后复述句子命题；指代词须能回指唯一名词；删除括号后主干仍须完整。

### 4.2 严谨、客观和克制

- **合格特征：** 判断强度与原文一致；“可能、表明、支持、限定于、不能外推”等边界表达保留完整。
- **需要修改：** 宣传性形容、无信息量的强调、口号式断言，以及语气强度在同一结论的不同位置发生漂移。
- **越界风险：** 将“支持”改成“证明”、将“关键条件”改成“必要条件”，或擅自增加、删除保留语。
- **判定方法：** 建立结论动词和情态词清单，逐项比较修改前后；结论的对象、范围和强度必须守恒。

### 4.3 简洁性与信息密度

- **合格特征：** 每句承担一个中心命题，或承担一组逻辑关系清楚的并列命题；必要限定紧邻其对象。
- **需要修改：** 同义复述、重复定义、“进行了……的……”式名词化、章节目录式罗列，以及一句中连续堆叠多个独立判断。
- **越界风险：** 把条件、例外、证据状态或交叉引用误删为“冗余”。
- **判定方法：** 对每个分句标注新增信息；没有新增信息且不承担衔接功能的成分才考虑删除。

### 4.4 中文句法的自然性

- **合格特征：** 主干靠前，修饰语贴近中心词，动词明确，并列成分词性和层级一致。
- **需要修改：** 英语式后置逻辑、过长“的”字链、名词连续堆叠、被动与主动主体混杂、分号承担过多逻辑层级。
- **越界风险：** 调整语序时改变条件范围、推导次序或比较关系。
- **判定方法：** 暂时将公式、模型名和引用替换为占位符后朗读；若句子仍需回读才能确定主干，则列为修改候选。

### 4.5 句间、段内及章节衔接

- **合格特征：** 段落按“主题—展开—限定或收束”推进；相邻句的信息承接可由关键词或明确逻辑关系识别。
- **需要修改：** 主题突然切换、前后重复总结、连接词过密、未有因果却使用“因此”，或仅用章节调度代替内容衔接。
- **越界风险：** 为增强连贯性而新增原文不存在的因果、递进或机制解释。
- **判定方法：** 给每句标注“定义、解释、条件、方法、结果、限制、过渡”等功能；相邻功能须能从原有语义中建立关系。

### 4.6 术语、指代和叙述主体一致性

- **合格特征：** 同一对象使用固定名称；简称在首次出现时定义；“本章／本节／本文”的指涉层级稳定。
- **需要修改：** 为避免重复而任意换用近义术语；“机械核心／机械子系统／力学部分”等在无定义转换时混用；“本文”与“本章”范围不清。
- **越界风险：** 把实际含义不同的近邻术语强行统一，或因替换叙述主体而扩大、缩小结论范围。
- **判定方法：** 审查前建立术语账本。默认以“本章”指当前章节的工作、实验和结论，以“本节”指局部内容；“本文”若可能指整篇学位论文而范围不确定，则保留并记录供作者决定，不机械替换。

### 4.7 博士论文书面语规范

- **合格特征：** 用语正式、具体、节制，同时保持中文自然表达。
- **需要修改：** “窜离”“主力模型”“头部组”“记账”等口语或内部工作语；“下一步”“此处先不展开”等备忘录式提示；宣传、口号或文学化表达。
- **越界风险：** 将已有明确技术含义的比喻性术语换成含义不同的新术语。
- **判定方法：** 检查表达是否适合直接出现在答辩送审稿中；若更像实验记录、团队备忘或口头汇报，则列为 B 类。

### 4.8 图表、公式和引用引导语

- **合格特征：** 公式前说明引入目的，公式后解释关键对象或作用；图表正文引导指出读者应观察什么；图题和表题自足但不过度承担讨论功能。
- **需要修改：** “如下图所示”式空引导、公式前后句法断裂、图题塞入过多推断和边界说明、表注重复整段正文。
- **越界风险：** 改写图题或表注时改变数据口径、统计定义、比较关系或结论。
- **判定方法：** 对每个图表和关键公式检查“引入—对象—读法—必要限定”是否完整；图题中的结论不得超出正文已有表述。

### 4.9 中文标点及中英文混排

- **合格特征：** 中文句子使用全角标点；公式作为句子成分时具有完整标点；英文缩写、模型名、数字、单位和区间格式前后一致。
- **需要修改：** 冒号、分号和破折号层级混乱；括号嵌套过深；中文与英文标点混用；正文、图题和表注中的单位形式不统一。
- **越界风险：** 误改公式、变量、数字、模型名、标签、引用键或 LaTeX 命令。
- **判定方法：** 对数字、单位、`\label`、`\ref`、`\eqref`、`\cite`、模型名和数学环境建立修改前后不变量清单。`60~s` 与 `\(60~\mathrm{s}\)` 等形式只作上下文适配检查，不机械跨数学／文本模式替换。

### 4.10 翻译腔、模板化表达和机器生成式重复

- **合格特征：** 使用具体主体和具体动词；相邻句各有明确的信息增量；重复术语服务于概念一致性，而非填充篇幅。
- **需要修改：** “可以看出”“值得注意的是”“从……角度来看”“在……方面”“进行了……的……”等低信息表达；连续多句采用同一空泛句式；反复预告或总结同一内容。
- **越界风险：** 将必要的技术术语重复误判为机器生成痕迹，或删除有导航作用的交叉引用。
- **判定方法：** 检查连续三句以上是否具有相同空壳结构；删除套话后若技术命题完整，则可删。本章实际风险主要集中在章节调度式元话语、局部同义重复和若干过载长句。

## 5. 标准应用示例

以下示例仅说明判定方式，正式修改仍须结合上下文复核。

1. **冗余，C 类**
   - 原句：“已有 AUV 研究已经利用神经网络处理……”
   - 建议：“已有 AUV 研究已利用神经网络处理……”
   - 说明：删除“已有／已经”的重复，不改变事实、范围或语气。

2. **并列层级过载，B 类**
   - 原句以一个长句连续列出非结构化离散模型的三重局限。
   - 建议：保留总起句，将固定采样间隔、训练—验证分布差异、物理结构缺失分别作为三个并列分句或短句。
   - 说明：不得改变三项局限的次序和因果关系。

3. **章节调度语气，B 类**
   - 原句：“本节规定回答该问题所需的实验设置：数据如何生成……各结构因素的定量作用在……报告……”
   - 建议：“本节依次说明数据生成、训练目标、对比模型与结构消融、评估方式、评价指标及初值扰动设置。各结构因素的定量结果见第……节。”
   - 说明：保留导航功能，删除低信息元话语。

4. **口语色彩，B 类**
   - 原句：“全状态黑箱预测窜离真值。”
   - 建议：“全状态黑箱的预测轨迹迅速偏离真值。”
   - 说明：“窜离”不符合博士论文书面语；“迅速偏离”保持原有方向和速度含义。

5. **内部工作隐喻，B 类**
   - 原句包含“该记账关系”和“功率记账”。
   - 建议：分别改为“该功率平衡关系”和“功率约束”。
   - 说明：使用正文已定义的规范术语，不改变所述结构关系。

## 6. 不属于本轮审查范围的问题

- 事实、数据、统计口径和实验结果是否正确；
- 公式、推导、命题条件和证明是否成立；
- 模型设计、实验协议和消融设置是否合理；
- 引用是否充分、文献内容是否支持正文；
- 证据是否足以支持结论；
- 数值异常的处理方式是否合理；
- 模型名称、变量、符号、数值、标签、引用键和交叉引用的实质调整；
- 章节结构、研究贡献和技术内容的增删；
- 结论强弱、因果方向、比较关系和适用范围的重定。

## 7. 全文审查与验证方式

1. 检查 Git 状态，并登记公式环境、数字、模型名、标签、引用键和图表文件等不变量。
2. 按摘要和十个正式章节顺序逐段处理，先解决 A、B 类问题，再审慎处理 C 类问题。
3. 复核跨章节术语、指代、“本文／本章／本节”、图表语言、单位格式和段落过渡。
4. 比较修改前后的公式、数字、引用和标签不变量。
5. 执行全文模式搜索、`git diff --check`、XeLaTeX 编译及日志检查，并抽查摘要、各节首尾段和章节过渡。
