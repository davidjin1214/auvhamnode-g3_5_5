# Legacy Phase-1 Comparison Matrix

This document archives the old Phase-1 comparison-matrix entry.

The active Phase-1 plan is:

- [../phase1_realistic_validation_plan.md](../phase1_realistic_validation_plan.md)

The previous matrix treated Phase-1 as a broad frozen experiment package covering multiple data layers, more models, more eval profiles, and a larger seed set. That design has been retired because it made the protocol itself too central and risked pulling the project away from the main scientific question:

```text
Can PHNODE / structured dynamics serve as the dynamics core for realistic AUV motion modeling and trajectory forecasting under matched-information conditions?
```

The current plan uses `Phase-1A` as a lightweight protocol-sensitivity check, not a full benchmark.
